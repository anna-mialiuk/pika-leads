# Переклади контенту з `src/data`

Кожен файл тут — переклад однойменного файлу з `src/data`:

    src/data/heroData.js  →  src/i18n/content/en/heroData.js
                          →  src/i18n/content/ru/heroData.js

Переклад **накладається** на українську версію (`src/i18n/merge.js`), тому в ньому
лише текстові поля — іконки, картинки, посилання й кольори беруться з оригіналу.
Чого немає в перекладі — показується українською.

## Правила

- **Масиви з `id` перекладаються за `id`**: `{ "complex-niches": { title: "..." } }`.
  Порядок не важливий — можна додавати й переставляти елементи в `src/data`.
- Масиви рядків без `id` (теги, списки) — за порядком.
- Числа в англійській пишіть у форматі `24,000` / `1,054.76`.

## Перевірка

    npm run i18n:check

Запускається автоматично перед `npm run build`. Підкаже, де бракує перекладу,
де переклад посилається на неіснуючий `id`, де лишився український текст.

## Дані в компонентах

    const { services } = useData("servicesData");

Назва — це ім'я файлу в `src/data`. Переклад поточної мови підтягується сам.
**Кейси й статті** — через хуки з `src/content/hooks.js` (див. `src/content/README.md`).

## Статті блогу

Тексти статей — JSON-блоки в `src/content/blog/<мова>/<id>.json`
(формат описано в `src/content/README.md`).
